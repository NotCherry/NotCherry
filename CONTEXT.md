# Dawid Portfolio Context

This context defines language for an honest personal portfolio: distinguish demonstrable work from ongoing learning and professional background.

## Portfolio language

**Public project**:
A personal or academic effort with a public artifact, demonstrable result, or evidence strong enough to support a case study.
_Avoid_: Project for every experiment, finished product when status is unknown

**Learning thread**:
An ongoing exploration, unfinished attempt, or technical idea that is valuable as part of Dawid's development story but is not presented as completed work.
_Avoid_: Failed project, shipped product, achievement claim

**Professional background**:
Work experience that informs Dawid's skills and perspective but is excluded from the first public portfolio version unless explicitly approved.
_Avoid_: Featured case study, public work claim

**Selected work**:
The small set of public projects shown as evidence on the page; it contains public projects only, not every skill or activity.
_Avoid_: Technology list, project dump, résumé archive

**Learning path**:
The connected story across software, robotics, infrastructure, and low-level study that explains what Dawid is becoming capable of.
_Avoid_: Linear career narrative, claim of expertise

## Current narrative terms

**Robot-learning education**:
The current direction for a simple educational site that lets students and less experienced learners perform imaginative tasks with URDF robots, with a possible later evolution toward resource-efficient robot training.
_Avoid_: Finished robotics platform, proven training system

**Unitree G1 exploration**:
A private learning thread involving a Unitree G1 humanoid robot, MuJoCo, skrl, and Python; its current value is the problem-solving story, not a claimed public result.
_Avoid_: Working locomotion system, completed robotics project
